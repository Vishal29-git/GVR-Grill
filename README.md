# 🚀 Project: GVR Grill Works

I built a responsive business website for **GVR Grill Works** using **React.js** to showcase their real fabrication and grill work projects.

## 🌐 Live Demo

https://gvr-grill-8qop.vercel.app/

## 💡 What I built

* A fully responsive website using **React.js**
* A gallery section to showcase real projects
* Separate navigation sections so visitors can easily explore their work:

  * Gates
  * Windows
  * Ladders
  * MS Steel
  * Balcony Designs
* Embedded **Google Maps** so customers can find the workshop easily
* A clean and simple UI focused on showcasing craftsmanship


## ⚙ Tech Stack

React.js | Vercel (Deployment)
